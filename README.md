Flow State App

Une application web de productivité permettant de gérer des tâches et d’améliorer la concentration grâce à un minuteur de type Pomodoro.

🚀 Fonctionnalités

✅ Création, modification et suppression de tâches

⏱️ Minuteur avec démarrer / pause / réinitialiser

📊 Barre de progression circulaire

💾 Sauvegarde des données dans le LocalStorage

📱 Interface responsive (mobile & desktop)

🔔 Notifications (toast messages)

🧭 Navigation dynamique avec hash (SPA)

🛠️ Technologies utilisées

HTML5

Tailwind CSS

JavaScript Vanilla (ES Modules)

API LocalStorage
